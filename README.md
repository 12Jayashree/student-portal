# 🎓 Student Portal

## 📌 Project Description

Student Portal is a simple web-based application designed to help students view their academic information in one place.

The project provides separate pages for:

- 📊 Student Dashboard
- 📅 Attendance
- 📚 Courses
- 🎓 CGPA
